# 连锁门店经营分析看板（经营决策驾驶舱）

把连锁零售 5 家门店 6 个月的经营数据，按**区域运营经理开月度经营会**的思路做成的交互式驾驶舱：先给经营结论与预算达成，再做营收 → 毛利 → 费用 → 净利的 P&L 拆解，覆盖客流转化、库存周转、品类与供应商采购，最后由规则引擎自动输出带测算金额的诊断，并生成可跟踪到责任人/期限/验收状态的行动计划（PDCA 闭环）。

🔗 在线演示：<https://46bzvs7m64-gif.github.io/mt-dashboard/>

## 功能模块

**全局交互**

- 月份切换（2026 年 4–9 月）+ 门店下钻（全网汇总 / 5 家单店），摘要、KPI、图表、诊断、行动计划全部实时联动；支持 ← / → 方向键切月
- 趋势柱可点击切月；门店表行 / 矩阵气泡点击下钻、再点返回全网

**经营会第一页：结论与目标**

- **本月经营摘要**：自动生成一句话定调（达标 / 增收不增利 / 双缺口）+ 营收面、盈利面、结构分化三条结论
- **预算达成**：年度预算按月分解到店，营收/净利双预算达成率、超收或缺口金额、进度条；趋势图叠加预算线、门店表含达成率列
- **TOP3 经营问题**：从诊断引擎按风险等级与影响金额自动取前三，点击直达诊断区

**经营分析（随筛选联动）**

- 8 项核心 KPI：营收（环比 + 同店同比 SSSG）、客单价、进店转化率、会员复购率、毛利率、净利率、坪效/人效、库存周转天数（含健康度分级）
- 营收 + 净利率 + **预算线** 6 个月双轴趋势图
- 门店对比表：营收 / **预算达成** / 环比 / 同比 / 客单价 / 转化率 / 毛利率 / 净利率 / 坪效 / 人效 / 周转 / 三色评级
- **门店分型矩阵（增长 × 盈利）**：净利率 × 同店同比四象限气泡图，气泡大小＝营收规模，自动归类明星店 / 现金牛 / 增收不增利 / 整改关停候选并给出组合策略
- 损益瀑布图（P&L Bridge）：营收 → 商品成本 → 毛利 → 房租/扣点 → 人力 → 其他 → 净利，每项标注占营收比
- **费用率趋势**：房租/人力/其他/合计费率 6 个月走势，监控费用杠杆是否刚性上行

**商品与采购（采销视角）**

- 品类结构：6 大品类「销售占比 vs 毛利贡献占比」双系列对比 + 品类毛利率，识别占货架不贡献毛利的品类
- 商品 ABC 帕累托图（8% SKU 贡献 70% 销售）+ 在售 SKU / 动销率 / 滞销 SKU / 库销比
- 供应商采购履约表：采购额、占比、账期、到货率、质检合格率、A/B/C 评级与整改备注
- 核心单品进价环比监控（涨跌双向色）+ 采购总额 / 加权账期 / 加权到货率 / A 级供应商占比

**决策输出与闭环**

- 促销 ROI 复盘：**增量毛利口径** ROI（增量营收 × 增量毛利率 ÷ 投入）+ 营收 ROI + 券核销率，自动给「保持复制 / 缩量观察 / 停投改造」决策
- 经营诊断规则引擎：亏损 90 天改善窗口、高坪效低净利重谈扣点、标杆店 SOP 复制、低毛利控折扣、库存积压、转化短板、供应商整改、促销止损、品类机会、同店负增长等 10+ 条规则
- 每条诊断均附**量化测算**（月增利 / 资金释放 / 止损上限），可按「增收机会 / 降本增效 / 风险预警」筛选
- **行动计划跟踪（PDCA）**：诊断一键转行动清单，自动匹配责任角色（店长 / 区域经理 / 采购经理 / 市场部 / 商品部）与验收期限（亏损店 90 天窗口、其余次月 15 日）；状态可推进「待启动 → 进行中 → 已完成 → 已验收」，闭环率实时统计并回写经营摘要；状态保存在本机浏览器，切到历史月份可追溯上月行动验收结果

## 使用

双击 `index.html`，无需联网、零第三方依赖（原生 HTML/CSS/JS + 手绘 SVG 图表），支持桌面与手机浏览器、支持浏览器直接打印月报。

## 数据说明

当前为**脱敏演示数据**（华东区 5 家虚构门店，2026 年 4–9 月，字段结构按连锁零售经营月报设计，确定性生成、可复现）。各店数据满足完整会计勾稽：`净利 = 营收 × 毛利率 − 房租 − 人力 − 其他费用`，全网 9 月 305 万营收 / 38.7% 毛利率 / 6.0% 净利率 / 预算达成 104.1%。真实使用时按门店月报字段替换数据源即可，指标计算、预算对比与诊断规则无需改动。

## 面试可讲（方法论）

- **经营会先讲结论再讲数字**：第一页回答「预算达成没有、同比好不好、钱的问题出在哪个杠杆、下个月谁去做什么」，明细图表只是论据
- **没有目标就没有管理**：年度预算按月分解到店，达成率 + 缺口金额让每个店长清楚自己离目标差多少；预算线与实际线同图，动作有没有效一眼可见
- **P&L 是连锁经营的通用语言**：营收 → 毛利 → 费用 → 净利，每个环节对应一个可干预的杠杆——毛利管品类结构与定价折扣、房租管选址与扣点谈判、人力管排班、库存管周转与滞销
- **多店经营是组合管理**：用「增长 × 盈利」矩阵把门店分成明星 / 现金牛 / 问题 / 瘦狗，资源投放、SOP 复制、整改关停用同一套语言决策
- **同店同比（SSSG）比总营收更真实**：剔除开关店影响后才看得出存量店的生意是在变大还是被分流；环比看上个月动作有没有效，店间对比找标杆和短板
- **三层效率漏斗**：客流 × 转化率 × 客单价 × 连带率 = 营收，坪效管人货场密度、人效排班合理性、周转管资金效率，任一指标异常都能定位到具体抓手
- **采销一体看毛利**：销售端用「销售占比 vs 毛利贡献」找结构性问题（引流品类 vs 利润品类），采购端管账期、到货率、供应商集中度与进价波动
- **促销必须用增量口径复盘**：增量营收要经毛利率折算成增量毛利再除以投入，否则低毛利清仓促销“看起来很热闹”实则赔本；券核销率反映活动真实吸引力
- **诊断的价值是给动作、给金额、给期限、给责任人**：不停留在报数字，而是「做什么 → 值多少钱 → 谁负责 → 什么时候验收」，并在下月经营会复盘闭环率（PDCA）
