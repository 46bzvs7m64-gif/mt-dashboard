# 连锁门店经营分析看板（管培生方向）

把连锁零售 5 家门店的营收、毛利、房租、人力、净利拆到「坪效 / 人效」口径的经营月报看板，自动输出经营诊断与行动建议——对标管培生轮岗中最常见的作业：看懂一家店的 P&L，并给出改善动作。

## 功能

- 核心指标：月营收、毛利率、净利率、坪效（元/㎡/月）、人效（万/人/月）、会员复购率
- 近 6 个月营收 + 净利率双轴趋势（柱线组合）
- 门店经营对比表（净利率三色分级：≥10% 优秀 / 5–10% 达标 / <5% 预警）
- 门店损益结构条（成本 / 房租 / 人力 / 其他 / 净利占营收比，亏损店红标）
- 促销活动 ROI 复盘（增量营收口径，自动给「保持 / 缩量 / 停投」建议）
- 经营诊断规则引擎：亏损预警 + 90 天改善窗口、标杆店 SOP 复制、高坪效低净利 → 谈扣点、低毛利 → 控折扣

## 使用

双击 `index.html`，无需联网、无第三方依赖（原生 HTML/CSS/JS + SVG 手绘图表）。

## 数据说明

当前为**脱敏演示数据**（华东区 5 家虚构门店，字段结构按连锁零售经营月报设计，确定性生成、可复现）。真实使用时将各门店月报按「门店/面积/人数/营收/毛利率/房租/人力/其他费用」字段替换数据源即可，诊断规则与展示逻辑无需改动。

## 面试可讲

- 管培生第一课是看懂 P&L：营收 → 毛利 → 费用 → 净利，每个环节对应一个可干预的杠杆——毛利管品类与定价、房租管选址与扣点、人力管排班、其他管损耗
- 坪效（营收/面积）和人效（营收/人数）是零售业跨店对比的通用语言：面积在换钱、人在换钱
- 诊断的价值是给动作而不是报数字：亏损店给 90 天改善窗口，标杆店沉淀 SOP 复制，高坪效低净利去谈扣点，低毛利控折扣深度
- 促销 ROI 必须用**增量口径**（活动期营收 − 同期基线），否则每场大促"看起来都赚钱"，这是很多门店复盘的隐形坑
- 看店三问：同比看趋势（生意在不在变大）、环比看动作（上个月做的事有没有效）、店间对比找标杆和短板（谁是模板、谁该治）
